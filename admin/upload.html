Cargar lista de precios

Subí el Excel del proveedor, elegí qué hojas y columnas usar, y confirmá antes de guardar. Todo el procesamiento del Excel se hace acá mismo en el navegador — el archivo no se sube a ningún servidor intermedio, solo los productos ya procesados van a la base al confirmar.

1. Elegí el proveedor y el archivo

¿Es un proveedor nuevo? Creálo primero acá y después volvé a esta pantalla.

Elegí las hojas a importar de ""

Detectamos hojas de producto (excluimos hojas auxiliares tipo "cotizador" o "variación de precios"). Para cada una, indicá qué marca y qué rubro le corresponde — por defecto usamos el nombre de la hoja como marca, y podés dejar el rubro vacío para que se use el "Rubro por defecto" de más abajo.

HojaMarca a asignarRubro (opcional)

Ojo: si desmarcás una hoja, mejor dejalas todas tildadas si no estás seguro. El rubro por hoja sirve cuando cada hoja es una marca distinta con un rubro claro (ej: Macroled → Iluminación LED, Chint → Electricidad); si la planilla ya tiene una columna de rubro/familia por fila, mapeála en el paso siguiente y esa tiene prioridad.

Si el proveedor separa los códigos de barras en otra hoja (con columnas de SKU y EAN por fila — se detectan solas por el título de la columna), elegila acá para completar el EAN13 de cada producto automáticamente. Si la lista no trae EAN, o ya viene en la misma hoja de cada marca, dejá "— No usar —" y mapeá la columna EAN en el paso siguiente si corresponde.

Mapeo de columnas

Mostrando la fila de encabezado y una fila de ejemplo de "". Este mapeo se aplica igual a todas las hojas elegidas (tienen que tener las mismas columnas).

Ojo con "caja master" vs "unidad de venta": si la planilla tiene las dos columnas, mapeá "unidad de venta" al campo de bulto — es la cantidad que realmente se vende como paquete cerrado. "Caja master" suele ser el embalaje grande del proveedor y da un umbral mucho más alto de lo que corresponde para el precio por bulto.
